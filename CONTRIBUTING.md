# Contributing

Contributions are welcome.

## Accepted contributions

- Complete templates
- Tools
- Snippets
- Workflows
- Configurations
- Documentation
- Tests
- Bug fixes
- Security improvements
- Examples

## Requirements

Do not submit secrets, credentials, malicious code, or material whose license
does not permit the intended use.

Complete templates should include documentation and metadata.

## Pull requests

Explain what changed, why it changed, and how it was tested.

Keep unrelated changes out of the same pull request.
