# SaaS Dashboard Starter

A framework-light SaaS dashboard foundation with an API boundary, organization
concept, settings screen, and client-side state.

## Structure

- `server/` HTTP API
- `web/` browser application
- `test/` API tests

This template intentionally avoids coupling the example to a payment provider
or identity provider. Add authentication, authorization, billing, persistence,
audit logging, and tenant isolation for a real SaaS deployment.
